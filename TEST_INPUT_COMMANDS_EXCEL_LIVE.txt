해석 실패 정책
- 모호/실패 명령은 `excel_live.list_workbooks`로 자동 폴백하지 않는다.
- 엑셀 작업 의도가 감지되는 러프 문장은 기본적으로 follow-up 질문(`excel_live.clarify` 또는 의도별 follow-up)으로 수렴한다.
- 비엑셀/무의미 입력은 HTTP 400을 유지한다.

- 서식/가독성: `보기 좋게 정리해줘`, `열 너비 맞춰줘`, `제목 행 고정해줘`
- 데이터 정리: `지저분한 거 정리해줘`, `중복된 거 없애줘`, `빈칸 채워줘`
- 텍스트 분리/결합: `이름/전화번호 나눠줘`, `도메인만 뽑아줘`, `여러 열 합쳐 문장으로 만들어줘`
- 날짜/시간: `지난달 데이터만 모아줘`, `마감까지 며칠 남았는지 계산해줘`, `근속연수 계산해줘`
- 숫자/금액/비율: `목표 대비 달성률 계산해줘`, `마진율 계산해줘`, `할인 적용 금액 계산해줘`
- 함수 도입형: `조건에 맞는 값만 더해줘`, `이름 넣으면 정보 자동 조회`, `오류면 확인 필요 표시`
- 조건 분류: `점수에 따라 등급`, `재고 부족 표시`, `마감 지나면 지연 표시`
- 정렬/필터/검색: `상위 10개만`, `문제 있는 행만`, `특정 단어 포함 행만`
- 집계/피벗/요약: `부서별 합계`, `월별 매출 정리`, `지역별 비교`
- 차트/대시보드: `월별 추이 차트`, `비율 차트`, `사장님 보고용 대시보드`
- 비교/검증: `전월 대비`, `두 시트 차이`, `수식 오류/형식 오류 점검`
- 보호/입력제한: `숫자만 입력`, `드롭다운`, `수식 셀 잠금`
- 자동화: `반복 작업 자동화`, `버튼 실행`, `데이터 추가 시 자동 반영`

시스템 설계 관점 체크포인트(라우터/슬롯/검증)
- 라우터는 최소 의도군 기준으로 분기: `CREATE_TABLE`, `FORMAT_SHEET`, `CLEAN_DATA`, `FORMULA_CALC`, `LOOKUP_MATCH`, `FILTER_SORT`, `AGGREGATE_SUMMARY`, `PIVOT_TABLE`, `CHART_VISUALIZE`, `DASHBOARD`, `VALIDATION_RULE`, `IMPORT_MERGE`, `AUTOMATION`, `DEBUG_FORMULA`, `PERFORMANCE`, `EXPORT_PRINT`, `EXPLAIN_HELP`, `SAFETY_PERMISSION`
- 멀티턴 필수 슬롯 기본집합: `task_goal`, `target_sheet`, `target_range`, `key_column`, `value_column`, `operation`, `output_location`, `error_policy`, `safety_policy`, `version_constraint`
- 실행 전 가드레일:
  - 삭제/덮어쓰기/매크로/외부링크/개인정보 작업은 승인 단계 필수
  - 원본 보존 기본값은 `원본 유지 + 결과 시트 생성`
  - 파일 권한(읽기전용/보호된 보기) 문제는 실행 전 상태 점검 우선
  - 편집 실행 전 복구 백업 생성(가능 시) + 실행/검증 실패 시 자동 롤백(best-effort) 적용
- 검증기 필수 체크:
  - 수식 샘플 값/행수/열수 일치
  - 결과 범위/차트 소스 범위 유효성
  - 원본 시트 보존 여부
  - 오류 셀(`##`, `#N/A`, `#VALUE`) 발생 여부

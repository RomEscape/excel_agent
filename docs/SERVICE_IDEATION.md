## 0. 한 줄 정의

> **"내 PC를, 내 보안 룰 안에서, 어디서든 메신저로 부리는 로컬 퍼스트 AI 에이전트."**

엘리베이터 피치:

> ChatGPT·Claude는 똑똑하지만 *남의 서버*에서 돈다. 내 파일·메일·코드를 맡기기 불안하다.
> Private-Claw는 **내 PC 안에서** 도는 AI 에이전트를, **텔레그램·슬랙·디스코드**로 원격 조종한다.
> 모든 위험한 동작은 실행 전에 **메신저로 승인**을 받고, 모든 행동은 **로컬 감사 로그**에 남는다.
> 클라우드 중계 서버는 없다. 데이터는 기기를 떠나지 않는다.

## 1. 왜 지금인가 (Why now)

세 흐름이 겹치는 지점에 제품이 있다.

| 흐름 | 신호 | 우리에게 주는 기회 |
|---|---|---|
| **로컬 LLM의 실용화** | Ollama로 phi/llama/qwen급 모델을 노트북에서 구동. "굳이 클라우드에 안 보내도 되는" 작업군이 커짐 | 로컬 추론을 기본값으로 둘 명분이 생김 |
| **프라이버시·컴플라이언스 압박** | 사내 보안정책상 사외 AI 서비스 금지인 조직 多. 개인도 민감 데이터 업로드 거부감 | "데이터가 기기를 안 떠난다"가 마케팅이 아니라 **구매 사유**가 됨 |
| **메신저 = 새로운 터미널** | 사람들은 이미 텔레그램/슬랙에 산다. 별도 앱을 안 켜고 채팅으로 일 시킴 | 모바일에서 내 데스크탑 풀파워를 쓰는 UX |

**한 문장**: "강력한 AI 에이전트"는 흔해졌지만, **"믿고 PC를 통째로 맡길 수 있는"** 에이전트는 아직 비어 있다. 우리는 *능력*이 아니라 *신뢰*를 판다.

## 2. 누구의 어떤 문제인가 (페르소나 & 페인)

### 페르소나 A — 보안 민감 개발자 / 1인 창업가 (1차 타겟)
- 코드·API 키·고객 데이터를 다룸. 외부 AI에 코드 통째로 붙여넣기가 꺼려짐.
- 외출 중에도 "빌드 한 번 돌려줘", "그 파일 읽어서 요약해줘"를 하고 싶음.
- **페인**: 원격 데스크탑은 무겁고, 클라우드 AI는 못 믿고, CLI 자동화는 직접 짜야 함.

### 페르소나 B — 보안정책상 사외 AI 금지인 팀 (2차 타겟)
- 회사 규정상 ChatGPT 사내 반입 불가. 그래도 AI 생산성은 원함.
- **페인**: "감사 가능하고(audit), 데이터가 안 나가고, 승인 흐름이 있는" AI가 필요한데 시중에 없음.

### 페르소나 C — 파워 유저 / 자동화 덕후 (확산 타겟)
- 이미 텔레그램 봇·n8n·단축어로 자기 워크플로를 짜는 사람.
- **페인**: 도구는 많은데 "내 PC의 파일/앱과 LLM을 안전하게 잇는" 접착제가 없음.

> 🟡 **논의**: 1차 타겟을 **개발자(A)** 로 좁힐지, 처음부터 **팀/조직(B)** 의 컴플라이언스 니즈를 노릴지. A는 확산이 빠르고(개인 결제), B는 객단가가 높지만(B2B) 세일즈 사이클이 김. 초기엔 A로 PMF 잡고 → B로 업셀 제안.

## 3. 핵심 가치 — 3개의 기둥

제품의 모든 기능은 이 3개 중 하나에 매핑되어야 한다. (안 되면 우선순위 후순위)

### 🛡️ 기둥 1. Zero-Trust Security — "실행 전에 막고, 실행 후에 남긴다"
- **정적 분석**: 모델이 만든 명령/코드를 실행 전 AST·정규식으로 검사 → `SAFE / CONFIRM / DENIED` 3등급.
- **HITL 승인**: `CONFIRM` 등급은 메신저로 인라인 버튼 [승인]/[거부]를 띄워 사람이 결정 (60초 타임아웃).
- **샌드박싱**: 워크스페이스 폴더 밖 접근 차단. 화이트리스트 기반.
- **감사 로그**: 모든 도구 호출을 로컬 JSONL에 append-only로 기록 → 보안 대시보드에서 조회.
- **PII 마스킹**: 응답에서 민감정보 마스킹, 차단 통계 노출.

> 이 기둥이 **유일한 진짜 해자(moat)**. "AI가 똑똑하다"는 카피되지만 "우리 보안 모델을 신뢰한다"는 평판은 시간이 든다.

### 🌍 기둥 2. Universal Accessibility — "어디서든, 이미 쓰는 채널로"
- 텔레그램·슬랙·디스코드(+ 향후 22채널) 어댑터. 별도 앱 설치 없이 채팅으로 PC 제어.
- NetBird / Tailscale P2P 터널 → 공인 IP 없이 집/회사 PC에 접근.
- 모바일에서 데스크탑 풀파워(로컬 모델 + 파일시스템 + 설치된 CLI 도구)를 호출.

### 🎁 기둥 3. Consumer-Ready UX — "비개발자도 5분 안에"
- 설치 마법사: LLM 선택 → 메신저 연결 → 워크스페이스 설정 원스텝.
- One-Click Ollama/OpenClaw 설치 (Homebrew 래핑, 실시간 로그).
- Permission Manager GUI: 허용 폴더/앱/화이트리스트를 코드 없이 토글.

> 🟡 **논의**: 3번(비개발자 UX)은 비싸다. 초기엔 **개발자가 감내할 수준의 거친 UX**로 출시하고, 3번은 B2B/대중화 단계에서 투자하는 게 맞다고 봄. (= 지금은 1, 2에 집중)

## 4. 핵심 사용 시나리오 (구체적으로)

추상적 가치를 **"손에 잡히는 30초 데모"** 로 바꾼 것. 데모/랜딩 카피의 원천.

### 시나리오 1 — 외출 중 코드 작업 위임 (페르소나 A)
```
[지하철, 텔레그램]
나: "office_claw 레포에서 어제 바꾼 파일들 테스트 돌려줘"
봇: ⚠️ `npm test` 실행을 요청합니다. [승인] [거부]
나: [승인]
봇: ✅ 12 passed, 0 failed. (로그 일부 첨부)
```
→ **가치**: 로컬 도구(npm) + 로컬 파일 + 승인 흐름. 클라우드 AI는 절대 못 함.

### 시나리오 2 — 민감 문서 요약 (페르소나 B)
```
나: "~/Workspace/계약서_초안.docx 핵심 조항만 뽑아줘"
봇: (로컬 Ollama로 처리) 📄 1. 계약기간… 2. 위약금… 3. 자동갱신…
```
→ **가치**: 문서가 **기기를 안 떠남**. 감사 로그에 "이 파일을 읽었다" 기록이 남음.

### 시나리오 3 — 위험 동작 차단 (3개 기둥의 교집합)
```
나: "임시파일 정리해줘"
봇: 🚫 `rm -rf /` 패턴이 감지되어 차단했습니다. (DENIED, 감사 로그 #1043)
```
→ **가치**: 모델이 실수하거나 악의적 프롬프트 인젝션이 들어와도 **로컬 가드레일**이 막음.

### 시나리오 4 — 팀 채널에서 공유 어시스턴트 (페르소나 B 확장)
```
[슬랙 #ops 채널]
동료: "@claw 어제 배포 로그에서 에러만 추려줘"
→ 승인은 PC 소유자에게만, 결과는 채널에 공유
```
→ 💡 **확장 아이디어**: "1 PC = 1 봇"을 넘어 **팀 공유 봇 + 소유자 승인** 모델.

## 5. 차별화 — 왜 대안이 아니라 우리인가

| 대안 | 그들의 강점 | 그들의 빈틈 = 우리의 자리 |
|---|---|---|
| **ChatGPT / Claude 데스크탑** | 최강 추론, 매끈한 UX | 데이터가 클라우드행. 내 파일/도구 직접 실행 못 함. 감사·승인 없음 |
| **Claude Code / Cursor 등 코딩 에이전트** | 개발 작업 강력 | 데스크탑 상주·원격 제어 아님. 비개발 작업·메신저 UX 없음 |
| **순정 OpenClaw** | 멀티채널·스킬 생태계 | **보안 레이어가 없음**. 마스킹·승인·샌드박스·감사를 직접 안 함 |
| **n8n / Zapier** | 워크플로 자동화 | LLM 자율 에이전트 아님. 로컬 파일시스템·로컬 모델과 약결합 |
| **원격 데스크탑 (RDP/VNC)** | 풀 제어 | 무겁고, AI 없고, 모바일 채팅 UX 아님. 감사·가드레일 없음 |

**우리의 한 칸**: *로컬 실행 × 보안 가드레일 × 메신저 원격 제어* — 이 세 축의 교집합에 우리만 있다.

> **핵심 인사이트**: 우리는 OpenClaw의 **경쟁자가 아니라 보안 래퍼**다. OpenClaw가 강해질수록(채널·스킬↑) 우리 가치도 커진다. "OpenClaw를 *안전하게* 쓰게 해주는 레이어" 포지션.

## 6. 제품 구조 — 서비스 관점 3계층

기술 스택이 아니라 **"사용자가 체감하는 가치"** 단위로 본 그림.

```
┌─────────────────────────────────────────────────────┐
│  ① 접점 (Reach)  — 사용자가 만지는 곳                 │
│    메신저(텔레그램/슬랙/디스코드) · 데스크탑 앱 UI      │
├─────────────────────────────────────────────────────┤
│  ② 신뢰 (Trust) — 우리의 해자                         │
│    정적분석 · 승인흐름 · 샌드박스 · 마스킹 · 감사로그    │
│    ⮕ 모든 입출력이 이 층을 반드시 통과                  │
├─────────────────────────────────────────────────────┤
│  ③ 두뇌 (Brain) — 교체 가능한 엔진                    │
│    OpenClaw 게이트웨이 + 로컬 Ollama (기본)            │
│    / Claude API (선택)                                │
└─────────────────────────────────────────────────────┘
```

- **②가 제품의 정체성.** ①(채널)과 ③(엔진)은 갈아끼울 수 있는 부품이고, ②(신뢰 계층)가 우리가 파는 본질.
- 엔진을 OpenClaw로 위임하는 전략 덕에 우리는 **에이전트 루프를 직접 안 만들고** 보안에만 집중 가능.

> 🟡 **논의**: ③ 엔진을 OpenClaw에 의존하는 리스크. OpenClaw의 프로토콜이 마이너 버전마다 깨진 전례 있음([`OPENCLAW_CLI_WRAPPER.md`](./OPENCLAW_CLI_WRAPPER.md) 참고 — 그래서 WS 직결 대신 CLI 래핑으로 우회). 엔진 추상화 레이어를 우리가 소유해서 "OpenClaw가 망해도 갈아끼운다"를 보장할 것.

## 7. 비즈니스 모델 아이데이션 💡

> 전부 가설. 검증 전. 토론용.

### 수익화 옵션
| 모델 | 설명 | 적합 타겟 | 메모 |
|---|---|---|---|
| **A. 오픈코어 + Pro 라이선스** | 코어 무료 OSS, 보안 대시보드·멀티채널·팀 기능은 유료 | A→B | 신뢰 제품이라 OSS로 코드 공개가 오히려 **신뢰 마케팅**이 됨 |
| **B. B2B 팀 시트** | 조직 단위 배포 + 중앙 정책(화이트리스트)·감사 리포트 | B | 객단가↑. 컴플라이언스가 결제 사유 |
| **C. 셀프호스트 + 지원 계약** | 제품은 무료, 설치/커스텀 보안룰 컨설팅 유료 | 규제산업(금융/의료) | 세일즈 무거움 |
| **D. 채널/스킬 마켓 수수료** | 검증된 보안 스킬 팩 판매 | C | 후순위, 생태계 성숙 후 |

> 💡 **추천 1차 가설**: **A(오픈코어)** 로 개발자 신뢰·확산 → 그중 팀이 생기면 **B(시트)** 로 업셀. "보안 제품은 닫힌 소스를 못 믿는다"는 역설을 활용.

### 배포 / 패키징
- 이미 Tauri로 `.dmg / .msi / .AppImage` + 서명된 자동 업데이트 파이프라인 보유 → **배포 비용이 낮음**(앱스토어 심사 우회 가능).
- 💡 "다운로드 → 마법사 5분 → 텔레그램에서 첫 명령" 까지의 **TTFV(Time To First Value)** 를 핵심 지표로.

## 9. 로드맵 — 서비스 마일스톤

기술 Phase(README)와 별개로, **"어떤 약속을 언제 지키나"** 관점.

| 단계 | 서비스 약속 | 상태 | 성공 기준(가설) |
|---|---|---|---|
| **M1. "내 PC를 폰으로 부린다"** | 텔레그램 → 파일/명령 + 승인 흐름 | ✅ 대체로 구현 (Phase 1~2) | 본인이 매일 씀(dogfooding) |
| **M2. "엔진을 OpenClaw로 위임"** | 메신저 → OpenClaw → 로컬 모델 한 바퀴 | 🟡 진행 중 (Rust CLI 래퍼 완료, Python 이관 잔여) | e2e 1회 성공 |
| **M3. "팀이 같이 쓴다"** | 멀티채널 + 중앙 권한/감사 | 부분 (Slack/Discord 어댑터 有, 팀 정책 미흡) | 외부 팀 1곳 파일럿 |
| **M4. "비개발자도 깐다"** | 온보딩 고도화 + Win/Linux | 일부 미완 (CHANGELOG 알려진 제한) | 비개발자 5분 내 첫 성공 |

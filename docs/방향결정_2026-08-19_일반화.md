# 방향 결정 (2026-08-19) — "내가 써 본 문장만 되는 룰베이스"에서 벗어나기

사용자 지적: "조금만 말을 바꿔도 오류. 너가 테스트해 본 말에 대해서만 고친 룰베이스지 강건한 게 아니다."
맞는 지적이다. 지금까지의 배터리(대화 각본 8개 × 5라운드, 사람 말투 48, 실사용 116)는 전부 **내가 쓴 문장**이라
회귀(안 흔들림)는 증명하지만 **일반화(처음 보는 문장)**는 증명하지 못한다. 이 문서는 2·3번 방향을 정하고
1번(측정)을 어떻게 돌리는지 적는다.

## 현재 구조의 천장

- 이해 층 = 규칙(좁고 정확) → 로컬 모델(넓지만 못 믿음). 로컬 모델은 A.X-4.0-Light **7.3B Q4**(일반 대화·분해)와
  그 SFT인 ax7bplanner(계획 JSON). 규칙을 놓치면 모델이 받는데, 모델이 좌표를 지어내거나 지시문을 값으로 쓰는
  일이 잦아 **확신 3분기**(규칙 실행 / 모델이면 해석 카드 / 모르면 되묻기)로 조용한 오염만 막아 왔다.
- 그래서 커버리지는 규칙으로만 늘고, 규칙은 본 문장만 넓힌다 → 땜질 루프. 하드웨어(RTX 4060 Ti 16GB, RAM 32GB)상
  로컬 모델 상한은 **~14B Q4**(32B는 VRAM 밖).

## 결정 3 — 모델 천장

1. **로컬 유지**(제품 전제 "PC에서만 처리"). 외부 API는 **옵트인 토글 설계만** 해 두고 지금은 켜지 않는다 —
   개인정보·비용·오프라인 전제가 바뀌는 결정이라 사용자 몫.
2. 같은 블라인드 세트로 **규칙 미스 구간**의 모델을 비교한다: ax7bplanner-v5r(7B SFT) vs 14B급 범용(qwen3:14b /
   gemma3:12b, 제로샷 + JSON 스키마). 14B가 "규칙 미스 → 정답 계획"을 유의미하게 올리면 카드 경로의 모델로 채택,
   아니면 2번(학습)이 지렛대.
3. 판정은 감이 아니라 블라인드 게이트 숫자(정답 실행률 ↑, 조용한 오실행률 = 0 유지, 되묻기율).

## 결정 2 — 정준 번역기(어떤 말투 → 정준 명령)

- 구조: 자유 문장 → **정준 문장**(규칙이 결정적으로 파싱하는 형태, 예: "합계를 표 아래에 한 줄로 넣어줘",
  "D2:D6 소수 첫째 자리") → 기존 규칙이 실행. 좌표·수식을 모델이 직접 내놓는 대신 **정준 문장**만 내놓게 하면
  지어낸 좌표는 파서 실패 → 되묻기로 떨어진다(조용한 오염 불가). 플래너 SFT(문장→계획 JSON)보다 표적이 작고 검증이
  쉽다.
- 데이터: **규칙이 라벨러다.** 배터리에서 규칙으로 정답 실행된 문장은 정준형을 안다 → 그 정준형의 패러프레이즈를
  만들면 (패러프레이즈, 정준) 쌍이 자동으로 생긴다. 블라인드 게이트의 문장도 과제별 정준이 있으니 쌍이 된다.
  목표 ≥ 3,000쌍(현재 `datasets/train/canonical_translate_v1.jsonl` 22쌍 + 오늘 블라인드 600+).
- 학습: `train/ax7b` 파이프라인(QLoRA, A.X-4.0-Light 7B, 4060 Ti에서 가능) 재사용, 평가는 **블라인드 held-out**
  (작성자가 다른 세트)으로. 게이트: 정준 변환 정확도 + 끝까지 돌린 정답 실행률이 규칙-only 기준선을 넘을 때만 배포.
- 배치: 라우터 입구에서 규칙 미스 시 번역기 호출 → 정준 문장으로 규칙 재시도 → 여전히 미스면 해석 카드/되묻기.
  번역기 신뢰도 낮으면 카드.

## 1 — 블라인드 게이트 (오늘 실행)

- `scripts/run_blind_paraphrase_gate.py`: 26개 과제(합계·평균·머리글 서식·테두리·콤마·정렬 2종·시트 생성·제목 쓰기·
  병합·틀 고정·조건 강조 2종·차트 2종·차트 삭제·범위 비우기·크로스시트 합계·붙여넣기 값·찾아바꾸기·시트 이름·
  두 셀 뺄셈·소수 자릿수·데이터 막대·열 너비·부정문). 정답은 **파일 상태 오라클**. 문장은 코드를 못 본 작성자
  3명(페르소나: 바쁜 팀장/신입/실무)이 과제당 8개씩, 총 600+.
- 분류: PASS_RULE / PASS_CARD / ASK / WRONG(카드 없이면 **조용한 오실행**) / ERROR.
- 정준 문장 교정 실행: 26/26 중 25 정답(17 규칙·8 카드), 1 오실행("소수 첫째 자리" → 모델 코드 0.1 → 코드는 규칙·대상은
  모델로 합치도록 수정). 카드 8건은 정준 문장조차 규칙이 못 잡는 기능(조건 강조 임계·찾아바꾸기·시트 이름·열 너비 등)
  — 그 기능들은 블라인드에서 모델 의존이다.
- 실패 문장은 규칙으로 막지 않고 **정준 번역기 학습 쌍**으로 모은다(실패 자동 수확).

## 하지 않을 것

- 블라인드 실패마다 정규식을 늘리는 것(지금까지의 루프). 2~3회 반복해 보이는 **패턴**(예: 지시어 생략, 어순 도치)만
  규칙의 **정규화 단계**로 올리고, 개별 문장은 데이터로 보낸다.

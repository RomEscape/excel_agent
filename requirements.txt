#
# 이 프로젝트는 여러 스택이 섞여 있어 package.json 하나로는 해결되지 않습니다:
#   - Node/React/Tauri  → package.json + npm ci
#   - Python sidecar    → python-sidecar/pyproject.toml (uv 권장) 또는 아래
#   - Rust/Tauri 네이티브 → Cargo.toml + Rust(rustup)
#   - LLM 모델          → Ollama (ollama pull …) — pip/npm 아님
#   - 에이전트 게이트웨이 → npm install -g openclaw
#
# conda/venv에서 sidecar만 설치할 때:
#   pip install -r requirements.txt
